# 🤖 AI Resume Assistant

An AI-powered Resume Assistant built using **Python** and **Large Language Models (LLMs)** that analyzes resumes, provides ATS-friendly improvement suggestions, identifies skill gaps, answers resume-related questions, and offers career guidance.

---

## 📌 Overview

AI Resume Assistant helps users improve their resumes by leveraging Generative AI. It extracts text from PDF resumes, analyzes the content using an LLM, and provides actionable feedback to enhance resume quality and ATS compatibility.

---

## ✨ Features

- 📄 Upload Resume (PDF)
- 🔍 Extract text from resume
- 🤖 AI-powered resume analysis
- 📈 ATS optimization suggestions
- 🛠 Skill gap analysis
- 📝 Professional resume summary generation
- 💬 Ask questions about your resume
- 🎯 Career improvement recommendations
- ⚡ Simple and easy-to-use interface

## 🚀 Installation

### Clone the Repository


### Navigate to the Project

```bash

```


## 📋 Workflow

1. Upload a PDF resume.
2. Extract resume text.
3. Send the extracted content to the LLM.
4. Analyze resume quality.
5. Generate ATS suggestions.
6. Identify missing skills.
7. Answer user questions about the resume.
8. Provide career recommendations.
